# Figma Imports

Reusable Tailwind CSS 4.3.2 primitive tokens for importing into Figma.

## Requirements

These files follow the Figma variables JSON format used by [import method/plugin].

## Color formats

Choose one:

- `tw_colors_hex.tokens.json`
- `tw_colors_oklch.tokens.json`

Do not import both into the same Figma file.

## Recommended import order

1. Colors
2. Spacing
3. Sizing
4. Borders
5. Typography
6. Effects
7. Layout
8. Motion

## Value conventions

- Spacing, sizing, radius, border width, blur and breakpoints use pixel numbers.
- Opacity uses values from 0–1.
- Line height uses unitless ratios.
- Letter spacing uses percentages.
- Transition duration uses milliseconds.
- Shadows and font families import as strings for reference or plugin use.

## Compatibility

Source: Tailwind CSS 4.3.2
